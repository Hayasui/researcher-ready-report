# 与 chinese-prose-style 的分工

两份技能同时在会话里时，边界按这份文件裁。判断一条规则归谁，先看它在语言层还是结构层，再对照第二节的归口表。

## 一、分工总原则

`chinese-prose-style` 管**语言层**：用词、句式、指称、主语、段落、翻译腔、禁用词、结构提示语、小标题不要抽象名词。

本技能（`researcher-ready-report`）管**结构层与信息分层**：七节骨架、五段模板、分母表、口径下沉、事实与解读标签、编号与结论式标题、数字写法、段落不复述表。

冲突时按这个顺序裁决：**用户明确要求 > 事实准确与合规 > 数据与术语准确 > 本技能的结构 > 默认文风**。但禁用词、翻译腔、主语缺失、段落盖章这几条语言底线，无论结构怎么定，都执行 `chinese-prose-style`。

## 二、重叠清单与归口

两份技能都在场时，按这张表判：

| 条款 | 归口 |
| --- | --- |
| 小标题写成结论句 | 本技能，报告独有 |
| 小标题不写抽象名词 | `chinese-prose-style`，本技能只引用 |
| 术语一物一名 | 通用部分归 `chinese-prose-style`；「变量名与题号只在术语表出现一次」归本技能 |
| 不自造复合简称 | `chinese-prose-style` |
| 删掉元话语 | 「交付／需求方／要写进报告」这类报告元话语归本技能；通用结构提示语归 `chinese-prose-style` |
| 段落不复述表格 | 本技能，报告独有 |
| 主语不能省 | 通用主语纪律归 `chinese-prose-style`；「比率说清谁占谁、选项名加引号、句间不悄悄换主语」归本技能 |
| 数字写法 | 本技能，报告独有 |

## 三、冲突裁决顺序

用户明确要求 > 事实准确与合规 > 数据与术语准确 > 本技能的结构 > 默认文风。

禁用词、翻译腔、主语缺失、段落盖章不在这个序列里让位——它们是语言底线，无论结构怎么定都执行 `chinese-prose-style`。反过来，本技能的结构要求也不因为文风偏好而撤：议题就五段，骨架就七节，摘要第一块就是分母表。

## 四、两份语体件的关系

`chinese-prose-style/references/report-writing.md` 是报告语体那一档：开篇交代什么、数字怎么就地读出分母、结论与建议分开写、方法与风险怎么摆。本技能是研究备忘录的结构骨架：七节怎么排、议题怎么分层、什么进正文什么下沉。两者互补，不重复——那一档管「一段话该怎么写」，本技能管「这些段落按什么顺序摆、哪一条放正文哪一条下沉」。

## 五、本技能不复制什么

本技能不复制 `chinese-prose-style` 的禁用词表、翻译腔表、段落规则。需要时直接去调用，别在这里造第二份：

- 禁用词、圈内行话、自造复合简称 → `chinese-prose-style/references/banned-words.md`
- 翻译腔迹象表 → `chinese-prose-style/references/translationese.md`
- 报告语体的细则 → `chinese-prose-style/references/report-writing.md`
- 语言层自检 → `chinese-prose-style/references/self-check.md`

同一件事在两份技能里只许有一个出处。本技能的这一份不重复写词表，只写结构；写完报告先过语言层的自检，再过本技能第五节的自检。
