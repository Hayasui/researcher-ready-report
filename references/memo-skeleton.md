# 交付骨架与议题范例

这是 SKILL.md 第 3 节的展开件。七节骨架每节要写什么、议题的五段模板、可复制的空骨架、一个填好的议题范例、常见的四处走偏，都在这份文件里。定骨架、填范例、写议题时读它。

## 一、七节骨架

固定七节，一节都不省。节标题写成名词短语，议题内的标题写成结论句；小标题要写清它说的是哪件事，不要拿「读法」这种要读者猜的抽象名词当路标。

```text
0  一页摘要             关键发现 6–8 条 + 未覆盖表 + 这些数字怎么读
1  研究范围、样本与精度  样本性质、ME 怎么读、术语表、未做的分析为什么没做
2..5  逐议题             每个议题走同一套五段模板
6  数据质量、限制与未覆盖  完整的一次性交代，正文不再重复提醒
7  对后续研究的建议      可验证假设、需要补的数据、现在就能补的分析
附录 A–C                完整表索引与关键补充表、值码与变量、脚本与复现路径
```

## 二、第 0 节：一页摘要

顺序是三块：分母表、关键发现、未覆盖表，末尾再给一句「这些数字怎么读」。

**分母表放在最前面**，列五样：名称、变量、指的是谁、人数、怎么来的（清洗掉了谁）。这张表一次说清全篇用到的几层人分别是什么，后面的百分比就只用写比例与层名，不必逐条展示分子分母。汇报时也靠它——说「MMORPG 玩家里有 38.6% 选收藏」就够了，不用解释 113/293 是怎么来的。

**关键发现 6 到 8 条**，每条一句判断加比例。比例写成「占 X 层的 56.7%」，主体放在句子里，分子分母留在表格里。

**未覆盖表列三项**：哪一项没做、状态、影响。影响要写成「报告因此回答不了什么」。

**末尾那一句**写清样本性质、ME 覆盖什么、子群多大的时候只读方向。

## 三、第 1 节：研究范围、样本与精度

样本来源与配额方式、剔除规则、ME 的算法与经验刻度（N 到多少时误差多大）、术语表。

术语表用三列：术语、定义、对应变量。首次定义之后全篇只用这一个说法。

未做的分析在这里给一句理由，详细留到第 6 节。

还要写清选项与游戏名的中文口径：问卷的日文原文与本文的中文写法怎么对应，去附录哪一张表查。

## 四、第 6 节：数据质量、限制与未覆盖

把口径问题一次说完：样本性质、分母口径、已知瑕疵、缺失题、未做的分析、度量约定。写完之后，正文里不许再出现「这一处口径需要注意」之类的提醒。

## 五、第 7 节：对后续研究的建议

分三类写：可验证假设（每条都要有支撑数字）、需要补的数据、不需要新数据就能补的分析（按对决策的用处排序，并写明小样本的处理规则）。

## 六、议题的固定五段模板

每个议题都用这五段，顺序不变，标题照抄：

```text
### 本议题回答什么
### 关键结论            编号列出，每条末尾挂分层标签
### 关键证据            图在前，表在后，只放关键项
### 口径与限制          只写本议题特有的；通用的在第 6 节
### 对后续研究的含义     可验证假设、要补的数据
```

**关键结论**每条一句，主语写出来，比例写成「占 X 层的 56.7%」，主体与分母在句子里就能看懂。末尾用方括号挂标签，只挂三类：`〔事实〕`可以直接引用，`〔解读〕`是推断需要谨慎，`〔事实／解读〕`是一句里两者都有。建议另起一句，用「建议验证」引出。标签的作用是让研究员一眼看出哪几个数字能进自己的 PPT。

**关键证据**只放支撑结论的那几项，完整表进附录并在附录里给出索引。图放前面，因为图比表快。表格标题写成结论句，不写「某某题分布」。

## 八、填好的议题范例

下面这一节是成稿的样子，参照它的语域与密度，不要参照它的题材。

```markdown
## 2　议题一　MMORPG 与 RO 的基本盘

### 本议题回答什么

MMORPG 在这批 RPG 玩家里的盘子有多大；RO 的存量按「听说过／玩过／还在玩」切开之后各是多少，还在玩的那一层是什么样的人。

### 关键结论

1. **MMORPG 已经是日本 RPG 玩家里的主流，不是小众。** 自认为 MMORPG 品类玩家的受访者占样本总量的 48.0%，在 17 个清单游戏里玩过至少一个的占 50.6%，现在还玩着其中至少一个的占 34.2%。〔事实〕两个口径之间有 52 人与 67 人的错位，说明这份清单只覆盖了大盘的一部分。〔解读〕

2. **RO 的瓶颈出在「玩过到还在玩」这一段，不在认知。** 326 人听说过至少一个《RO》游戏，127 人玩过，61 人现在还在玩；玩过《RO》的 127 人里已经有 52.0% 离开。〔事实〕

3. **现在还在玩 RO 的玩家没有把 RO 放在第一位。** 61 人里只有 21 人主玩的游戏是《RO》系作品，28 人主玩的游戏是「ファイナルファンタジーXIV」。〔事实〕RO 在这批人身上的角色是「还在玩的一个」，不是「最投入的一个」。〔解读〕

### 关键证据

图 1　RO 的存量是三层，分母不同不能相减

![](figures/fig01_ro_funnel.png)

表 1　RO 三层与同基数转化

| 层与转化 | 计数/基数（占比，±ME） |
| --- | --- |
| 听说过至少一个《RO》游戏 | 326/579（56.3%，±4.0pp） |
| 玩过至少一个《RO》游戏 | 127/510（24.9%，±3.8pp） |
| 现在还玩着至少一个《RO》游戏 | 61/293（20.8%，±4.6pp） |
| 同基数：玩过的人里还在玩 | 61/127（48.0%，±8.7pp） |
| 折到全卷 579：还在玩至少一个《RO》游戏 | 61/579（10.5%，±2.5pp） |

### 口径与限制

Q3 问的是「曾经玩过」，不设时间窗，所以 50.6% 是累计口径，当下口径看 34.2%。三个层级的基数分别是 579、510、293，不能相减当漏斗读。

### 对后续研究的含义

可验证假设：拉新瓶颈在 IP 认知到试玩的转化，不在品类的兴趣。支撑是 IP 自评第三层（213 人）里 23.5% 表达了试玩意愿，而障碍首位是「对这个系列没有兴趣」37.7%。
```

## 九、常见的四处走偏

**把摘要写成目录。**「本报告第一节讲样本，第二节讲议题一」是目录，不是摘要。摘要的每一条都要是结论加比例。

**把解读写进事实条。**「主玩的游戏高度集中，说明玩家忠诚度高」——后半句是推断，要么另起一句挂〔解读〕，要么删掉。

**主语缺失或缩写过度。**「自认 MMORPG 品类的 48.0%」「最吸引人的体验是故事与世界」这两句都不说是谁。改成「自认为是 MMORPG 品类玩家的受访者占样本总量的 48.0%」「MMORPG 玩家觉得最吸引人的体验是「故事与世界观」」。

**在正文里重复提醒口径。** 同一件事在第 1 节、第 2 节、脚注、结尾各说一遍，读者每读一节都要停下来重算一次分母。说一次，然后引用节号。
