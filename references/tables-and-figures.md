# 表与图

做表、画图、给图表编号与写标题时读这份。写正文时交叉引用图表也从这里查编号规则。

## 一、表

编号（表 1、表 2……附录用表 A1、A2），标题写结论，正文按编号交叉引用。只保留关键项，完整项进附录。列数超过四列就考虑拆成两张，或者把「计数/基数（占比，±ME）」压成一列。

完整分布表不进正文，只给索引，索引写在附录 A。

## 二、图

用图替代大表的五种场景：份额与构成（漏斗、堆叠条）、排序（水平条）、两组同基数的对照（分组条）、跨档位的连续变化（折线）、一题多面板的并列。

每张图满足三条：

1. 比例带 ME 误差棒，图注写清误差棒是什么。
2. 图里写出 n，因为这类项目的分母逐题不同。
3. 标题写成结论句；图后不再复述图里的数字。

## 三、样式与配色

配色跟着客户的主题色走，先用主题色定主调，再补一个次调。客户的主题色是单色（例如橙）时，系列色就用**同一色相的深／浅两调**，不要为了区分两批去凑蓝与青绿两个色相——那样图里的颜色和客户的主题色没有任何关系，业务方一眼能看出来。网格、误差棒、坐标轴文字走中性或暖灰，别用第三个彩色。深色给主体（样本量大的那批、基准那一组），浅色给对照。

浅底深字，去掉上右边框。中文字体用系统里的雅黑或思源一类，先注册再画。画图脚本单独成文件并写进附录的复现路径，不要散在对话里。

**数值标签落在误差棒末端之外。** 标签的横坐标要按「条形末端 + 该点 ME + 余量」算，只加一个固定量会让标签正好停在误差棒的棒线与端帽上，两者叠在一起——这处毛病画的时候不容易看出来，出图后要把图打开逐个看一眼。放宽横轴上限时也要给标签留出地方，否则末位的标签会被裁掉。

**出图脚本的 `--check` 可以对到字节。** 同一台机器、同一份 matplotlib 与字体，Agg 后端写出的 PNG 是确定性的：`--check` 里把图重画一遍写到内存，与盘上的文件比字节，一致才算过。这样锁住的不只是「图用的数据与产物同值」，还有「盘上那张图确实是从这份数据画出来的」。

## 四、scripts/plot_style.py

`scripts/plot_style.py` 是现成的样式与画法：注册中文字体、水平条（带 ME）、分组条、百分比堆叠条，直接 import 用。

```python
import plot_style as ps

ps.setup()                                   # 注册中文字体 + 设定配色与字体大小
fig, ax = ps.figure()
ps.hbar(ax, labels, counts, base)            # counts 是计数，base 是基数，ME 自动算
ps.save(fig, "figures/fig01_xxx.png", "图 1　结论式标题")
```

文件里另外备着四种画法，按第二节的场景选：`grouped_hbar`（两组同基数对照，各组的基数可以不同，图注里要写清分母是否相同）、`stacked_pct_hbar`（份额与构成）、`line_with_notes`（跨档位的连续变化，每个点旁边写比例与 n）。绘图只依赖 matplotlib，不依赖 pandas。

`grouped_hbar` 默认按 `TINTS` 取同色相的深浅两调并自动给棒末写数值，`colors` 可换整组系列色，`xlim` 不传时按「最大值 + ME」再留两成余量算。`hbar` 的数值标签同样落在误差棒之外。

找不到中文字体时它会退回默认字体，图里的中文会变成方块，所以画完要看一眼。
